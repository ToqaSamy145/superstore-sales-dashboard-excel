# 📊 Superstore Sales Dashboard (Excel)

An interactive Excel dashboard analyzing sales and profit performance for a retail superstore, covering the period **2016–2019**. Built using **Pivot Tables**, **Pivot Charts**, and slicers for dynamic filtering.

## 📁 Contents

The workbook includes the following sheets:

| Sheet | Description |
|---|---|
| **Dash3** | Main dashboard summarizing total sales, profit, and order count with a regional filter |
| **category sales by region** | Sales & profit breakdown by product category |
| **sales by sub-category** | Sales breakdown by product sub-category |
| **sales by region** | Sales, profit, and quantity by region (Central, East, South, West) |
| **months trends** | Monthly sales trends across years (2016–2019) |
| **customer segmention** | Sales breakdown by customer segment (Consumer, Corporate, Home Office) |
| **Total Orders** | Total count of orders |

## Key Insights

- **Total Sales:** ~$2.3M | **Total Profit:** ~$286K | **Total Orders:** 9,993
- **Top Category:** Technology (highest profit)
- **Top Region:** West (highest sales & profit)
- **Top Sub-Category:** Phones (highest sales)
